A lightweight, fast, and fully customizable WordPress theme with deep Elementor compatibility.

== Description ==

HelloTurbo is a performance-focused WordPress theme designed for speed and flexibility. It features an advanced Customizer with Header Builder, Footer Builder, global color palette, typography controls, button styling, sidebar management, blog/archive layouts, single post options, page layout settings, and breadcrumbs.

Fully compatible with Elementor, WooCommerce, and all major plugins. Includes full-width and canvas page templates for page builders.

== Features ==

* Lightweight and fast (under 50KB CSS)
* Header Builder with Above/Primary/Below header rows
* Footer Builder with widget areas and copyright bar
* Global color palette (9 colors)
* Typography controls (body + headings + H1-H6 individual sizes)
* Button styling (colors, radius, padding, weight)
* Sidebar controls per content type (pages, posts, archives, WooCommerce)
* Blog/Archive layouts (list, grid, masonry)
* Single Post options (title layout, featured image, meta, related posts)
* Breadcrumbs with multiple source support
* Elementor full-width and canvas page templates
* Mobile-responsive navigation with animated hamburger menu
* WooCommerce ready
* Translation ready
* Accessibility ready (skip links, ARIA labels, keyboard navigation)

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Search for "HelloTurbo" or upload the helloturbo.zip file.
3. Click Install and then Activate.
4. Navigate to HelloTurbo in the admin menu for the dashboard.
5. Use Appearance > Customize to configure the theme.

== Frequently Asked Questions ==

= Does this theme require Elementor? =

No. HelloTurbo works with any page builder or the default WordPress block editor. It has enhanced compatibility with Elementor for full-width layouts and header/footer building.

= Is this theme compatible with WooCommerce? =

Yes. HelloTurbo includes WooCommerce support out of the box.

= How do I customize the header and footer? =

Go to Appearance > Customize > Header Builder or Footer Builder panels.
