# hello-turbo-theme

HelloTurbo — a lightweight, fast, and fully customizable WordPress theme.

## Description

HelloTurbo works seamlessly with Elementor, Gutenberg, and all major page builders. It features an advanced Customizer with Header Builder, Footer Builder, global color palette, typography controls, button styling, sidebar management, blog/archive layouts, single post options, and breadcrumbs.

See [readme.txt](readme.txt) for the full feature list, changelog, and installation instructions.
